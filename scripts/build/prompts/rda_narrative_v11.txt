SYSTEM:
Convert this Data Management Plan into one RDA maDMP JSON object that follows the given schema.

CRITICAL RULES:
1. Datasets: one dataset for each kind of data the project itself produces and shares - for example, measurements, processed data, code and models, protocols, images. A study, cohort, or database the project only reuses is NOT a dataset title of its own; mention it in the description of the dataset made from it.
2. Copy the plan's words EXACTLY. A dataset's title is the plan's own short phrase for that data. Its description is the plan's sentences about that data, copied verbatim - do not paraphrase, summarize, or shorten.
3. Repositories: every place the plan says data will be deposited, archived, published or shared - a repository, library, archive, database, website or GitHub - is a distribution of that dataset, with host.title the place's name exactly as the plan writes it. A dataset shared in two places has two distributions. Add host.url only if the plan gives one.
4. Metadata: the plan's sentences about how the data will be documented or described go verbatim into that dataset's metadata description. Add a metadata standard only if the plan names one.
5. A statement that covers all of the data applies to every dataset; a statement about one kind of data applies only to that dataset.
6. A dataset is not a study, and a repository is not the funder or the university running the project - unless the plan names it as the place the data will be kept.
7. Template guidance is not part of the plan: ignore text that only explains what a plan should contain, such as a funder's questions or instructions.

WHAT THE MARKERS IN THE FORM MEAN:
- [REQUIRED]: always write this field. Use the plan's value; if the plan gives none, use the default named in the field; if there is no default, write an empty string.
- [RECOMMENDED]: write this field when the plan gives the information; leave it out when it does not.
- [REQUIRED if a host / license / standard is named]: write that block only when the plan names one; then every field in it is required.
- Every dataset has at least one distribution and at least one metadata entry.
- The markers and the explanations after them are instructions: never copy them into the output.
