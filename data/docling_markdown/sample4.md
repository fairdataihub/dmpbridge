## Oxide Surfaces, From Bulk to Nanoparticles

## Types of data produced

Types of data, samples, physical collections, software, curriculum materials, and other materials to be produced in the course of the project.

There will be in general x types of data generated for this research. The following will outline each type and how it will all be collected, processed, and stored.

1.  Transmission electron microscopy (TEM) images
1.  File type: .dm3, .dm4, .tiff, etc. (image files)
2.  Captured: Using TEMs at different facilities
3.  Processed: Generally using DigitalMicrograph, but also ImageJ, MacTempasX, and other types of image analysis programs
2.  X-ray diffraction patterns
1.  File type: .txt
2.  Captured: Using X-ray diffractometers
3.  Processed: Will be plotted in Origin or similar data plotting software. Data analysis will primarily be conducted using MDI Jade. Python or Mathematica may be employed for further analysis.
3.  Sample statistics
1.  File type: Likely spreadsheets (.xlsx)
2.  Captured: Will vary, likely couting statistics
3.  Processed: Will vary depending on what is being measured
4.  Spectorscopy (e.g. EDX, EELS, XPS)
1.  File type: Native software file types
2.  Captured: TEMs
3.  Processed: Native software, Python, Mathematica, etc.

## Quality Assurance/Control

All data will be analyzed for any relevant information for each experiment. In addition, all data will be saved for future reference in case any more information is needed for future analysis.

## Data and metadata standards

Standards to be used for data and metadata format and content (where existing standards are absent or deemed inadequate, this should be documented along with any proposed

## solutions or remedies).

All data acquired will be linked back to the specific sample tested. The samples are typically nanoparticles, which will be identified according to the date synthesized. Synthesis conditions and post-processing will be notated in a lab notebook accordingly.

In addition, metadata may be needed for the instrument conditions used for acquiring. In general, these will apply for each type of data:

## 1.  TEM

- Microscope used
- Accelerating voltage
- Imaging/Diffraction mode
- Relevant apertures
- Probe size
- Camera length

## 2.  XRD

1.  Instrument used
2.  X-ray source
3.  Acquisition time
3.  Spectroscopy
1.  Instrument used
2.  Relevant settings (e.g. probe size)
3.  Acquisiton time
4.  Any data smoothing or processing method
5.  Normalization method used

Metadata will be stored primarily in the file name of each dataset acquired. Additionally, it may be notated in the lab notebook used when acquiring.

Policies for access and sharing, and provisions for appropriate protection/privacy

Policies for access and sharing; Provisions for appropriate protection of privacy, confidentiality, security, intellectual property, or other rights or requirements.

All data will be stored on the research group RAID server, which may be made available in a shared folder upon request. Depending on the type of data, specific software may be needed to read propietary file formats. Such details will be explained if requested. ## Policies and provisions for re-use, re-distribution

## Policies and provisions for re-use, re-distribution, and the production of derivatives.

Permission to re-use or re-distribute data will be granted within reasonable request. The source of the data must be adequately acknowleged if used, and the appropriate citation should be made if available.

## Plans for archiving and preservation

## Plans for archiving data, samples, and other research products, and for preservation of access to them.

All data will be stored and archived in our research group's RAID server, which already incorporates data redundancy for backups. It will remain there for at least 5 years after the release of the corresponding publication or project. All data require for the creation of a research manuscript will be stored. Additional data acquired will also be stored for future reference in the research group. Data may be compressed as necessary for data sharing. Metadata files will be stored in appropriate directories to detail what is being stored in the server.
